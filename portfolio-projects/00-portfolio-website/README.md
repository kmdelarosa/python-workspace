# Portfolio Website

A personal software engineering portfolio site showcasing Python projects built alongside the Udemy Complete Python Bootcamp.

## Portfolio Description

A clean, responsive portfolio website presenting my background, skills, and Python projects. Each project includes a description, tech stack, and a live demo or interactive preview. Built to grow alongside my development journey — new projects are added as they are completed.

## Pages

| Page | Description |
|------|-------------|
| Home / Hero | Introduction, tagline, and call-to-action links |
| About | Background, skills, and learning journey |
| Projects | Cards for each project with descriptions and demo links |
| Contact | Contact form and social/GitHub links |

## Projects Featured

1. CLI Expense Tracker
2. Password Generator
3. Personal Finance Dashboard
4. Web Scraper — Job Listings
5. Automated File Organizer
6. PDF Report Generator
7. Email Automation Tool
8. Flask REST API — Notes App

## Tech Stack (Website)

- HTML5, CSS3, Vanilla JavaScript
- No framework — keeping it simple and learnable
- Deployed via GitHub Pages (free)

## Getting Started

Open `mockup.html` in a browser to preview the full design.

For the final site, open `index.html` in a browser or deploy to GitHub Pages:

```bash
# GitHub Pages — push to main branch
# Then enable Pages in repo Settings → Pages → Deploy from branch
```

## Design Notes

- Color palette: dark navy (`#0f172a`) + electric blue accent (`#3b82f6`) + white
- Font: Inter (Google Fonts)
- Mobile-first responsive layout
- Project cards link to a modal with a sample/demo of each project
